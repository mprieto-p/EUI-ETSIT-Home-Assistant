# EUI-ETSIT-Home-Assistant
Este repositorio contiene la configuración del dashboard desarrollado en Home Assistant para el Espacio Urbano Inteligente de la ETSIT.

El código incluye la organización de vistas, entidades, sensores, automatizaciones, scripts y tarjetas utilizadas para supervisar servicios como alumbrado, riego, consumo energético, residuos, aparcamiento y variables ambientales.

También incluye el conjunto de los datasheets de los dispositivos propuestos.

Este repositorio forma parte del Trabajo Fin de Grado "Diseño e implementación del Espacio Urbano Inteligente de la ETSIT".
